Wofür der API-Key?

Mit einem YouTube Data API v3 Key kannst du nach Videos suchen, ohne den Player zu unterbrechen. Der Key ist kostenlos und erlaubt bis zu 4900 Videoabfragen pro Tag.

Wofür der Last.fm-Key?

Mit einem Last.fm API Key kann die App ähnliche Künstler zum gerade laufenden Video finden und darauf basierend bessere Videovorschläge machen. Der Key ist kostenlos.
